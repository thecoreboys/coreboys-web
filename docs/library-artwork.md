# Library banner artwork

Created with the built-in image generation tool for the CORE library invitation.

Project asset: `public/design/library-studio-v1.webp` (1600 × 640, 47,066 bytes). The source PNG remains in the generated images directory. The project asset preserves the composition and uses WebP compression; the page loads it lazily through Next Image.

Final generation prompt:

> Create a photorealistic editorial website banner background for an independent creator video library. Cinematic close-up of a real professional broadcast editing desk: tactile dark charcoal control surface, machined knobs, illuminated ivory and restrained warm red keys, a small stack of black SD memory cards, out-of-focus studio monitors showing only abstract soft light, no legible screens. Sophisticated, calm, premium photographic product styling, subtle film grain and realistic material detail, soft directional light, black and warm graphite palette with restrained burgundy reflections. Wide horizontal landscape composition about 2.5:1. Objects and interesting details concentrated in the right half; left half dark negative space for real website headings that will be added in code. No text, no letters, no logos, no people, no fake social posts, no neon gradients, no glowing circuitry, no artificial UI illustration.
