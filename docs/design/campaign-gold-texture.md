# Campaign gold texture

Asset: `public/brand/campaign-gold-texture-v1.webp`.

Generated with the built-in image generation tool, then encoded as a 1600-pixel-wide WebP for the campaign background. The surface uses static CSS gradients over the texture; it does not animate the bitmap.
